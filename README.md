Semana de Tecnologia UEMG

Projeto acadêmico desenvolvido como parte das atividades avaliativas da disciplina de **Fundamentos de Programação para Web**, do curso de Bacharelado em Sistemas de Informação da Universidade do Estado de Minas Gerais (UEMG) – Unidade Carangola.

## Sobre o projeto

O projeto consiste no desenvolvimento de uma página web informativa para apresentar a Semana de Tecnologia, um evento voltado à divulgação do conhecimento, da inovação e de diferentes áreas da tecnologia.

A página apresenta informações sobre o evento, minicursos disponíveis e orientações de contato com a organização.

Funcionalidades

- Apresentação da Semana de Tecnologia.
- Menu de navegação entre as seções da página.
- Listagem dos minicursos e suas respectivas cargas horárias.
- Interação com o visitante por meio de uma mensagem de boas-vindas personalizada.
- Possibilidade de alteração da cor de fundo da página por escolha do visitante.

Tecnologias utilizadas

- HTML5: estruturação e organização do conteúdo da página.
- CSS3: estilização dos elementos, cores, alinhamentos e formatação visual.
- JavaScript: implementação das interações e funcionalidades dinâmicas.

Estrutura do projeto

```text
semana-de-tecnologia-uemg/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Interaja com a página e teste as funcionalidades disponíveis.
